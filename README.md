# Skunk

A phone-first tracker for how much time you spend on your hobbies each week, and how much time and money your "skunks" (bad habits) cost you.

Plain HTML, CSS and JavaScript with no build step. Data is saved in the browser on your device; use Export on the History tab for backups.

Live at https://brixhazen.github.io/skunk/. On iPhone, open it in Safari and choose Share → Add to Home Screen.
